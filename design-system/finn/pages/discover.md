# FINN editorial experience

User reference: https://dribbble.com/shots/27566031-Website-Design-for-Industrial-Designer-Mirko-Romanelli

Adapted qualities: an offwhite canvas, large restrained typography, thin divisions, original material imagery, image-led project cards and a numbered editorial sequence. FINN retains emerald as its accent. No reference screenshots or designer artwork are included in the product.

Verified skill guidance: `minimal editorial portfolio --domain style` returned Minimalism & Swiss Style, appropriate for an enterprise tool. `prefers reduced motion --domain ux` returned reduced-motion and excessive-motion guidance. The aggregate design-system search returned an unsuitable marketing gateway; its layout/dark palette were rejected. A React motion search and one narrower retry found no match; standard React effect cleanup and platform media-query patterns are implementation fallbacks, not claimed skill search results.

Discover is the default fifth workspace view. Existing Briefing, Portfolio, Research and Saved remain directly available. Three original illustrative research cards open native preview dialogs and prefill a real research question. Financial case-study periods remain visible; artwork conveys a material/editorial concept, not market evidence. The company explorer filters the actual 18-company mock watchlist.

Motion: finite staggered hero entrance, scroll reveal, small pointer-only image tilt, hover zoom, accordion reveal and modal entrance. No perpetual animation, scroll hijacking, canvas or motion dependency. Native scrolling and image dimensions preserve layout. User pause control persists locally; system reduced motion always wins. All actions have button/keyboard equivalents; horizontal mobile cards have previous/next controls.

Palette: ivory #F7F7F4, charcoal #232727, forest #235B45, muted text #5C6662, thin border #D9DED8. Existing Manrope/DM Sans fonts retained. Shared navigation moves to a compact horizontal bar; mobile uses five labelled bottom destinations. The original dashboard remains an information workspace, with the editorial gallery as an optional entry into it.

Assets: three local 1448x1086 WebPs, approximately 243 KB combined. Details and prompts in public/images/ASSET_PROVENANCE.md. Explicit dimensions reserve image space; secondary cards/portfolio tiles are lazy loaded. Hero/gallery and workbench sections use responsive layouts at 375, 768, 1024 and 1440 pixels.
